# TerminalFix Windows Cleaner

Una herramienta de mantenimiento y limpieza para Windows desarrollada por TerminalFix.

**🇦🇷 Español | 🇺🇸 [English](README.md)**

## Características

* Limpieza de archivos temporales
* Limpieza de la caché de Windows Update
* Limpieza de cachés de navegadores
* Limpieza de la caché DNS
* Vaciado de la papelera de reciclaje
* Limpieza de componentes de Windows mediante DISM
* Modo de limpieza completa
* Detección de permisos de administrador
* Medición del espacio libre en disco

## Uso

1. Descargar `Windows-Cleaner.bat`
2. Ejecutarlo como administrador
3. Seleccionar la opción deseada

## Compatibilidad

* Windows 7
* Windows 8
* Windows 8.1
* Windows 10
* Windows 11

> Algunas funciones pueden comportarse de manera diferente según la versión de Windows.

## Objetivo

Facilitar las tareas de mantenimiento de Windows, especialmente en equipos con recursos de hardware limitados.
